# first-year intro to engineering project with a group of 5

## Wearable-Help-System Summary
Portable device that sounds a buzzer after a button is pressed or the user blows into the sensor.

##  Objective: 
Bring necessary support to the user when in dire situations by sounding a buzzer that grabs the attention of people in range
